# Тестовые модели чата — 10 октября 2026

В выборе модели добавлена отдельная группа «Тестируется». В неё входят MiMo V2.6 Flash (4 VC), Euryale 3.3 (18 VC), Euryale 3.1 (23 VC), Aion 3.0 Mini (22 VC) и Aion 3.5 Mini (38 VC). Рубли за миллион токенов взяты из указанных владельцем котировок, используются как каталоговая оценка, не как подтверждённое списание провайдера.

## Настройки запросов

- MiMo: запрашиваем отключение рассуждений через `reasoning.enabled=false`, лимит 1000 токенов выхода.
- Euryale: 1000 токенов выхода, без параметров рассуждений.
- Aion 3.0 Mini: запрашиваем `reasoning.effort=none`, `enabled=false`, `exclude=true`; общий лимит 1000. Прямой API Aion разрешает none, однако снятый другим чатом каталог OpenRouter помечает модель mandatory=true, а каталог KodikRouter перечисляет reasoning без reasoning_effort. Поэтому выполнение режима шлюзом НЕ подтверждено. Владелец явно выбрал доступный тестовый режим за 22 VC с ограничением и предупреждением. Предупреждение всегда видно рядом с моделью, включая мобильный экран. Возможен короткий или пустой ответ при расходовании лимита на внутренние рассуждения.
- Aion 3.5 Mini: `reasoning.effort=low`, `exclude=true`, общий лимит 4000. Он покрывает рассуждения и видимый ответ вместе. Это НЕ гарантия «3000 рассуждений + 1000 ответа», не резервирование и не отдельный лимит рассуждений. 38 VC — предварительная фиксированная цена, фактический расход не измерен.

Параметры общие для stream/non-stream вызовов чата, включая регенерацию. Для тестовых моделей ожидание открытия потока/HTTP-ответа увеличено с 30 до 60 секунд; обычные модели сохраняют прежние настройки. При расчёте окна входа резервируется фактический лимит выхода: для Aion 3.5 Mini при maxContextTokens=20000 остаётся 16000 токенов входа «Вселенной»; остальные модели сохраняют резерв 1000. Вход дополнительно ограничен тарифом: Старт/Диалог 6000, История 10000, Вселенная 16000. 20000 — общий технический потолок приложения, а не объём каждого запроса и не нативная вместимость провайдера. Из потока по-прежнему показывается только delta.content; скрытие reasoning не отключает его и не отменяет оплату. completion_tokens уже включает рассуждения, повторно добавлять их к стоимости выхода нельзя.

Источник настроек Aion: https://www.aionlabs.ai/docs/api-reference/ (none у 3.0; low/high/max и обязательные рассуждения у 3.5; общий max_tokens).
Источник формата reasoning шлюза OpenRouter: https://openrouter.ai/docs/guides/best-practices/reasoning-tokens.
Общее описание параметров KodikRouter: https://www.kodikrouter.ru/docs/gateway. Оно не доказывает исполнение конкретного режима через этот шлюз. Платные live-вызовы в рамках этой доработки не выполнялись.

## Каталог и выпуск

Данные подготовлены в `prisma/migrations/20261010190000_chat_testing_models/migration.sql`. SQL добавляет только пять моделей; повторный запуск обновляет их котировки, сохраняя существующие id, остальные модели и пользовательский выбор. Следующий SQL, prisma/migrations/20261010200000_chat_context_limits/migration.sql, устанавливает общий потолок 20000 у всех 14 известных моделей, меняя только maxContextTokens. Новые колонки не требуются. API вычисляет isTesting по имени; экспериментальные модели не становятся базовыми по умолчанию.

Relaxdev ранее удалял migrate deploy из сборки. Сначала выложить код с гостевым ограничением, затем нужен бэкап и применение обоих конкретных SQL в указанном порядке через Adminer (лучше целиком внутри BEGIN/COMMIT), либо штатная миграция при настроенной истории Prisma. Не запускать prisma/seed.js на production: существующий скрипт удаляет каталог и сбрасывает выбор пользователей. SQL к production не применялся. В seed обновлены только лимиты девяти существующих моделей до 20000; его разрушительное поведение не изменено.

После SQL и выкладки проверить /api/models, группу в настройках чата, цену списания и фактический usage у первых ответов. Для Aion 3.0 отдельно подтвердить исполнение отключения reasoning; если шлюз его не исполняет, пересмотреть режим/цену или отключить модель. Для Aion 3.5 проверить долю пустых ответов, задержку и стоимость на разных длинах контекста. Не считать новые модели проверенными по одним синтетическим тестам.
