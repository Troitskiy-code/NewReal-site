# Подключение DeepInfra — 11.10.2026

Статус: реализация и изолированные проверки завершены; код подготовлен к базовой выкладке с обоими переключателями на `kodikrouter`. Production SQL и реальные запросы к DeepInfra в рамках реализации не выполнялись. Применение каталога после подтверждения нового деплоя — отдельная задача, исходный статус записан в `docs/deepinfra-production-catalog-migration-2026-10-11.md`. Улучшение скорости и стабильности ещё требует измерения на реальных запросах.

## Переключение провайдера

- `src/lib/aiProviders.ts` задаёт два независимых переключателя: `CHAT_AI_PROVIDER` для ответов, повторной генерации и гостевого чата; `MEMORY_AI_PROVIDER` для текстовых задач памяти, анализа намерений, событий персонажей и создания промптов. Значения: `kodikrouter` или `deepinfra`. При отсутствии значения сохраняется KodikRouter; неизвестное значение вызывает ошибку конфигурации.
- `src/lib/aiTextClient.ts` направляет служебные задачи в выбранный сервис. При DeepInfra заменяет модель и авторизацию, убирает настройки reasoning и service tier прежнего шлюза, сохраняет температуру и ограничение конкретной задачи. Сводка «Вселенная» сохраняет 1500 токенов выхода, остальные текстовые задачи — свои меньшие лимиты, максимум 1000.
- `src/lib/chatHelpers.ts` использует один выбранный маршрут для каждого ответа. Автоматической смены провайдера или модели нет. Повтор сетевой ошибки/429 возможен до получения потока; частичный поток повторно не запускается. Код возврата VC остаётся общим для двух провайдеров.
- Адрес DeepInfra фиксирован: `https://api.deepinfra.com/v1/openai/chat/completions`. Авторизованные запросы не следуют перенаправлениям. Таймер действует до окончания потока, а не только до заголовков; для DeepInfra предел — 60 секунд на попытку.
- `src/lib/deepinfraModels.ts` и JSON-каталог содержат только публичные параметры моделей, без секретов. Серверные переменные DeepInfra читаются через `process.env['…']`, чтобы избежать заглушек необязательных переменных в Relaxdev.

Для всех новых строк `maxContextTokens=20000` — технический потолок общей вместимости в существующей системе. Входные продуктовые лимиты сохраняются: 6000 / 10000 / 16000 токенов по тарифу. Выход ограничен 1000 токенов, включая рассуждения. У пяти моделей с поддержкой reasoning запрашивается `reasoning_effort: "none"`; выполнение этого режима реальным API ещё не подтверждено. Тестовые данные не доказывают качество, отсутствие рассуждений или достаточность выхода при включённом reasoning.

Для полного отказа от KodikRouter понадобится отдельный выбор embedding-модели, перенос/пересчёт индекса и проверка поиска. `KODIKROUTER_API_KEY` пока нужен.

## Учёт расходов

`aiCostTelemetry.ts` различает провайдера по разрешённому адресу. DeepInfra записывает `provider=deepinfra`, поверхность `chat_completions`, токены, доступные request/response ID и каждую отдельную попытку. Native cost берётся из `usage.estimated_cost`; поле KodikRouter `usage.cost` не используется для DeepInfra.

- `providerCostCurrency=USD`, `providerCostSemantics=provider_estimated_usd`.
- Перевод в рубли: native estimate × `DEEPINFRA_USD_RUB`.
- Если native estimate отсутствует, используется оценка по USD-тарифам каталога и этому же курсу, когда хватает данных о токенах.
- Без положительного конечного `DEEPINFRA_USD_RUB` рублёвая стоимость остаётся неизвестной. Курс ЦБ и `AI_COST_USD_RUB` не подставляются за DeepInfra.
- `reportedCostRub` не выдаёт оценку за подтверждённое списание. Новые источники `deepinfra_usd_estimate` / `deepinfra_catalog_estimate` учтены в отчёте экономики.
- Известные расходы частичного неудачного ответа сохраняются; успешная продажа VC при этом не записывается. Reasoning-токены не прибавляются повторно к общему completion count.

Основание для 108,192: подтверждённые пользователем 5 долларов на баланс за 5,25 долларов с карты при 103,04 ₽/$: `5.25 × 103.04 / 5`. Это стоимость зачисленного доллара с комиссией пополнения, а не валютный курс ЦБ. Цены VC основаны на плановом сценарии нагрузки, а не на измеренной марже после перехода.

Официальные документы: [OpenAI-compatible API](https://docs.deepinfra.com/chat/overview), [Streaming](https://docs.deepinfra.com/chat/streaming), [Reasoning](https://docs.deepinfra.com/chat/reasoning), [пример ответа с estimated_cost](https://deepinfra.com/XiaomiMiMo/MiMo-V2.6-Flash/api).

## Порядок выпуска и ручная приёмка

1. В Relaxdev добавить `DEEPINFRA_API_KEY` и `DEEPINFRA_USD_RUB=108.192`. До SQL оставить `CHAT_AI_PROVIDER=kodikrouter` и `MEMORY_AI_PROVIDER=kodikrouter`. Ключ KodikRouter сохранить для эмбеддингов.
2. Сначала выложить проверенный код с обоими переключателями на `kodikrouter` и подтвердить, что production использует новую фильтрацию каталога. Старый код не знает префикс `deepinfra:` и может показать эти активные модели либо отправить их в KodikRouter; поэтому SQL нельзя применять до этой выкладки.
3. После свежего бэкапа применить весь SQL каталога одной транзакцией. В production ранее отсутствовала `_prisma_migrations`; полный `prisma migrate deploy` старой истории не запускать. Убедиться, что 11 новых моделей присутствуют, старые записи и пользовательские выборы сохранены. Только после этого включить `CHAT_AI_PROVIDER=deepinfra` и перезапустить приложение согласно механизму Relaxdev. Для служебных задач отдельно включить `MEMORY_AI_PROVIDER=deepinfra` после проверки их качества. Дополнительный cron не нужен.
4. На реальных запросах проверить русский язык и ролевой стиль каждой модели, отсутствие скрытого перерасхода reasoning, SSE completion/usage, скорость первого токена и ответа, сохранение результата, одну оплату и соответствующий `AiCostEvent`. Для памяти проверить правильный JSON сводки/классификации и отсутствие потери фактов. Проверить, что эмбеддинги по-прежнему создаются.
5. Сопоставить оценки с расходами кабинета DeepInfra; измерить затраты по тарифам и реальную частоту ошибок. До этого экономика и выигрыш в стабильности остаются предварительными.

Откат: вернуть соответствующий переключатель на `kodikrouter` и перезапустить приложение. SQL удалять не нужно. Истории диалогов и старые векторы этим переключением не меняются.
