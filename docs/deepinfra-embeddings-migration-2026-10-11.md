## Модель и API

Выбрана `Qwen/Qwen3-Embedding-0.6B`, 1024 измерения. Модель поддерживает русский и другие языки; официальная цена DeepInfra на дату проверки — $0,01 / 1M входных токенов. Источники: [DeepInfra API и цена](https://deepinfra.com/Qwen/Qwen3-Embedding-0.6B/api), [размерности и рекомендации Qwen](https://github.com/QwenLM/Qwen3-Embedding).

Endpoint фиксирован: `https://api.deepinfra.com/v1/openai/embeddings`. Выход запрашивается как `float`; пользовательские URL и модели не принимаются. Для поискового вопроса добавляется инструкция Qwen `Instruct: ...\nQuery: ...`; документы и тексты semantic dedup передаются без инструкции. Смена модели или обработки текста требует нового хранилища и пересчёта, даже если размерность совпала.

## Что изменилось

- `src/lib/embeddingProviders.ts`: `EMBEDDING_AI_PROVIDER=deepinfra|kodikrouter|disabled`. Если переменная отсутствует/пуста, используется `MEMORY_AI_PROVIDER`. В DeepInfra берётся только `DEEPINFRA_API_KEY`, независимо от переданного старого ключа. Ошибки настройки закрывают вызов, автоматического fallback в KodikRouter нет.
- `src/lib/embeddingClient.ts`: единый клиент RAG и semantic dedup, пакеты до 32 текстов, общий дедлайн на пакетную операцию. Проверяются число строк, уникальные индексы, модель, размерность, конечные числа и ненулевой вектор. Вход длиннее 64 000 символов отклоняется без API; это защитный предел, не обещание определённого числа токенов.
- `src/lib/memoryEmbeddings.ts`: временные сравнения фактов используют нового провайдера. Исторического индекса здесь нет, пересчёт не нужен. При отказе клиента остаётся существующий консервативный запасной алгоритм.
- `src/lib/messageEmbeddings.ts`: поиск и запись используют отдельную таблицу `MessageEmbeddingDeepinfra` (`vector(1024)`). Старую `MessageEmbedding` (`vector(1536)`) код DeepInfra не использует для расстояний. Пользователь, персонаж, исключённые сообщения и границы времени остаются в SQL. Поздний ответ API не записывается, если исходный текст изменился. Продолжение/перегенерация очищают устаревшие векторы обеих таблиц, даже при смене тарифа. Удаление сообщения каскадно удаляет новый вектор.
- Поисковое API ограничено 3 секундами, фоновое/semantic dedup — 8 секундами. Лимит относится к запросу провайдера; операции БД и запись телеметрии вне этого сетевого лимита. Ошибка поиска возвращает пустые цитаты и позволяет чату работать с последними сообщениями, фактами и summary.
- Учёт в `AiCostEvent`: provider=`deepinfra`, apiSurface=`embeddings`, входные токены из `usage`, выходные — 0. При наличии документированного `usage.estimated_cost` хранится USD-оценка; иначе вход оценивается по $0,01/1M и `DEEPINFRA_USD_RUB`. Значение `cost` из чужого контракта не интерпретируется как списание. Без проверенного курса рублёвая оценка остаётся неизвестной; `reportedCostRub` не заполняется.
- `src/lib/embeddingBackfill.ts` и `/api/cron/backfill-embeddings`: GET только считает остаток/готовые записи, POST обрабатывает до 10 сообщений. По умолчанию пересчитываются сообщения пользователей с действующей платной подпиской; `ENABLE_RAG_EMBEDDINGS=true` расширяет обработку на всех. Сначала идут новые сообщения. Готовые векторы пропускаются; проверка текущего содержимого защищает от изменения/удаления во время вызова. Уникальный ключ защищает от двойной записи. Блокировка с владельцем и временем БД не даёт двум cron-работникам одновременно обрабатывать пачку. Это не гарантия ровно одного платного вызова при гонке с обычной фоновой записью нового сообщения.
- При первом отказе пачка останавливается и получает 60-секундную паузу; POST возвращает 503 с безопасными счётчиками. GET/POST защищены существующим `CRON_SECRET`; в логах нет текста сообщений или ключей. Не создаётся фоновый автоматический запуск всей истории при старте приложения.

## БД и порядок выкладки

Миграция: `prisma/migrations/20261011230000_deepinfra_embeddings/migration.sql`. Создаются только `MessageEmbeddingDeepinfra`, уникальный индекс `messageId`, HNSW cosine-индекс и `EmbeddingBackfillLease`. Никакие старые векторы, сообщения, промпты, core/episodic memory или summary не удаляются.

1. Свежий бэкап Timeweb.
2. В Adminer выполнить **точный SQL миграции между BEGIN и COMMIT**. `SET LOCAL` ограничивает ожидание блокировки 5 секундами и SQL 60 секундами. При ошибке — ROLLBACK, не продолжать отдельные команды. Проверить наличие таблиц, тип `vector(1024)`, FK и обоих индексов. SQL не предназначен для слепого повторного запуска. Если объекты уже есть, сначала проверить их схему. Не запускать полный `prisma migrate deploy` на базе без истории.
3. Выложить код после SQL. Новая таблица нужна даже при выключенном DeepInfra: обновление сообщения инвалидирует оба индекса. Prisma Client должен быть сгенерирован из новой схемы.
4. В Relaxdev выставить `CHAT_AI_PROVIDER=deepinfra`, `MEMORY_AI_PROVIDER=deepinfra`, `EMBEDDING_AI_PROVIDER=deepinfra`. `DEEPINFRA_API_KEY` уже используется чатом. Сохранить фактический `DEEPINFRA_USD_RUB`; не заменять курсом ЦБ.
5. Отправить обычное сообщение в платном диалоге. Проверить новую строку в `MessageEmbeddingDeepinfra` и `AiCostEvent`: DeepInfra/embeddings, 1024 измерения, input > 0, output=0, оценка RUB. В логах не должно быть новых обращений к KodikRouter при всех трёх переключателях DeepInfra.
6. Прочитать GET статуса. Затем отдельно запустить POST пересчёта. Для cron подходит POST раз в минуту; прекратить исторический пересчёт, когда remaining=0. Обычная запись новых сообщений продолжится без этого cron. Старые сообщения доступны в RAG DeepInfra только после получения нового вектора, последние сообщения и текстовая память работают сразу.
7. Проверить на русском запросы по старой переписке, отрицаниям, именам, отменённым обещаниям и сохранности разных фактов. Порог cosine 0,80 и минимальный RAG-порог 0,25 перенесены из прежней настройки; их качество на Qwen требует отдельной живой приёмки. Изолированные числовые тесты не подтверждают качество модели и скорость реального API.

Адрес: `https://newvers.ai/api/cron/backfill-embeddings`. Предпочтительный секрет — заголовок `x-cron-secret` или `Authorization: Bearer ...`, а не query URL. GET не создаёт платных запросов. POST запускает платные эмбеддинги; суммарную стоимость всего архива до измерения токенов не обещаем.

При отказе DeepInfra можно поставить `EMBEDDING_AI_PROVIDER=disabled`: поиск продолжит работу без семантических цитат и не будет вызывать другой сервис. Откат на `kodikrouter` возвращает только старое векторное пространство; новые сообщения без старого вектора там не найдутся. Старый ключ можно убрать, когда chat, memory и embeddings подтверждены на DeepInfra и откат на KodikRouter больше не нужен. Старую таблицу сейчас не удалять.
