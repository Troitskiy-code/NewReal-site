## Новая регрессия в `src/lib/logger.ts:97–108`

`formatErrorLogArg` рекурсивно обходит массив через `arg.slice(0, 32).map(formatErrorLogArg)`, но не передаёт WeakSet, глубину или общий бюджет обхода. Ограничение в 32 элемента не ограничивает повторное посещение одного и того же массива.

Минимальный случай:

```js
const a = [];
a.push(a, a);
formatErrorLog("Probe", ["constant event", a]);
```

Независимый probe вызывает настоящий formatter в отдельном дочернем процессе без Logtail/сети. Контроль `[1, 2]` завершается с exit 0 за 378 мс вместе со стартом процесса. Циклический массив входит в formatter, но не завершает его за 3 секунды; дочерний процесс принудительно остановлен по таймауту. Это воспроизводимый синхронный зависающий обход, который удерживает event loop при таком входе.

Утечка credentials в этом probe не проверялась и не обнаруживалась: это дефект устойчивости нового логгера. Влияние на доступность реального HTTP endpoint не воспроизводилось. Прошедший тест циклов в `redactSensitive` проверяет другой обход, где WeakSet и MAX_DEPTH сохранились; новый error formatter этот обход для массивов не использует.

## Узкая доработка для Cursor

1. В `formatErrorLogArg` учитывать seen/WeakSet **до** обхода массива/Map, ограничить глубину и желательно общий бюджет посещений. Повторное посещение и превышение лимита возвращают постоянную безопасную заглушку. Альтернатива — не обходить неизвестные контейнеры ошибок, а сразу возвращать безопасную категорию.
2. Сохранить исправленный контракт unknown errors и разрешённого контекста. Не возвращать прежнюю эвристику и не расширять работу на Метрику/P1/экономику.
3. Добавить проверки через настоящий `formatErrorLog`/`errorLog`: массив с одним и двумя ссылками на себя, смешанный цикл и превышение глубины. Проверять своевременное завершение и безопасный вывод в console/mock sink. Проверку потенциально зависающего входа запускать в дочернем процессе с таймаутом.
4. Повторить 104 проверки и оба harness; `node docs/p0-security-logger-cycle-probe.cjs` должен показывать completed=true, exit=0, timedOut=false для обоих случаев. Production-ротацию не выполнять из агента.

Артефакты: `docs/p0-security-logger-cycle-probe.cjs` и `docs/p0-security-logger-cycle-probe.json`. Exit 0 самого probe означает сохранение результатов; timedOut=true внутри результата означает дефект formatter.

Продуктовый код, production, Метрика, тарифы и экономика в этом ревью не менялись. Коммит/push и ротация не выполнялись.
