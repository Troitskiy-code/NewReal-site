## Транзакция

Один запрос Adminer с включённым «Остановить при ошибке»:

1. `BEGIN`, `SET LOCAL lock_timeout = '5s'`, `SET LOCAL statement_timeout = '60s'`.
2. Семь `INSERT … ON CONFLICT ("name") DO UPDATE` из файла миграции (без комментариев).
3. Проверка `SELECT 1/(CASE WHEN … THEN 1 ELSE 0 END) AS catalog_ok`. При любом несоответствии она делит на ноль и останавливает выполнение до `COMMIT`. Условия:
   - всего 39 строк, из них 18 `deepinfra:`;
   - 7 пилотных строк с ожидаемыми именами — активны, не бесплатны, окно 20000;
   - отпечаток прежних строк и отпечаток выбора моделей пользователями не изменились.
4. `COMMIT`.

Каждый INSERT изменил одну запись, `catalog_ok = 1`, `COMMIT` выполнен. Другие миграции, seed, `db push` и `_prisma_migrations` не запускались.

## Порядок с деплоем

SQL безопасен в любом порядке с кодом:
- старый код показывает только имена из своего JSON, поэтому новые строки скрыты;
- новый код показывает только те имена, которые есть в БД.

Новые модели появятся в выборе после деплоя коммита с обновлённым `deepinfra-chat-models-2026-10-11.json`, и только при `CHAT_AI_PROVIDER=deepinfra`.
