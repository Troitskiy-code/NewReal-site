# Ответы поддержки через Resend

Администратор открывает `/ru/admin/support`, вводит существующий ADMIN_SECRET (только память вкладки), выбирает тикет и сохраняет ответ. API требует Bearer авторизацию даже для чтения. Получатель берётся исключительно из тикета. Текст отправляется без HTML, секреты, текст обращения и email не логируются.

SupportReply хранит ответ, фиксированные sender/recipient, уникальный clientKey, хеш содержимого, состояние и идентификатор Resend. Повтор запроса с тем же ключом не создаёт второе письмо; другое содержимое возвращает 409. Cron deliver-support обрабатывает одну исходную заявку и один ответ за запуск. Повторные попытки ограничены шестью и 23 часами; используется стабильный ключ Resend и claim с fencing. Dead требует ручного разбора, автоматического повторного начисления/отправки за пределами окна нет.

`accepted` означает принятие Resend, а не доказанную доставку. Delivery webhook и входящая почта не реализованы. Письмо предлагает продолжить через форму поддержки с номером тикета; новое обращение автоматически не объединяется со старым.

До запуска применить `20261006120000_support_replies`; проверить существующие RESEND_API_KEY, ADMIN_SECRET и cron. Опциональная SUPPORT_FROM_EMAIL: `NewVerse Support <support@newvers.ai>`, это же значение используется по умолчанию. Домен newvers.ai должен быть подтверждён у Resend. Никаких production-писем проверки не отправляют.

Проверено: `node scripts/verify-support-replies.mjs` — настоящая миграция на частном PostgreSQL, реальные API/очередь с подставным отправителем (авторизация, получатель, конкурентные запросы, идемпотентность, retry, истечение окна, защита от cross-site). `node scripts/verify-support-browser.mjs` — Edge 390/1280, открытие тикета, ответ, отсутствие ключа в storage и очистка при выходе. TypeScript, ESLint изменённых файлов, сборка с синтетическими env, P0 security (118), P0/P1 (40) прошли. Сборка имеет прежнее предупреждение трассировки next.config/currencyRates. Production-миграция и реальная доставка ещё не проверены; commit/push не выполнялись.
