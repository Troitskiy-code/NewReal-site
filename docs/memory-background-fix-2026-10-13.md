# Background memory refresh, 13 October 2026

Read-only technical evidence: 34 DeepInfra Mistral summary requests between 08:08 and 08:27 Moscow received HTTP 200. Twenty-seven used exactly 200 completion tokens; 26 of those ended within 1.5 seconds of a JSON SyntaxError log. The old pipeline shared the stored summary allowance with the generated JSON, did not inspect finish_reason, and retried the unchanged backlog on subsequent messages. Two embedding attempts ended at 7997/7999 ms against an 8000 ms deadline. Message and summary bodies were not read during this investigation.

The stored allowances remain 200/500/800/1500 tokens. Generated JSON receives 768/1134/1584/2634 tokens, with an absolute service ceiling of 4096. DeepInfra receives a strict JSON schema with required keys, allowed statuses and per-request source IDs. The legacy route requests a JSON object. Both still validate grounding and fit complete facts into the stored allowance. A length finish reason is rejected before parsing. Parse, structure, source and empty-result failures have allowlisted diagnostic codes; logs contain no generated text or source bodies.

Background refresh acquires a database lease for 180 seconds, using the existing EmbeddingBackfillLease store under a disjoint memory-summary:<thread SHA256> namespace. This requires no migration or new environment variable. A failed refresh retains a 120-second cooldown across processes and restarts. Success deletes only its own claim; an expired owner cannot release a successor. Existing optimistic coverage/text checks remain the final write guard. Manual rebuild retains its explicit user flow and its existing write guard.

Oversized backlogs shrink to a bounded whole-message prefix, oldest first. Equal-timestamp groups are never split, and only the selected prefix advances coverage. A single message that cannot fit is refused rather than silently marked summarized. Catch-up proceeds on later eligible refreshes. No immediate extra paid retry or provider fallback is introduced.

Background document/dedup embeddings now have a 25000 ms total deadline; interactive RAG query embeddings retain their 3000 ms bound. The existing backfill failure cooldown and isolated vector stores remain in place.
