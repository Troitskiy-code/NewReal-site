## Настройки и вместимость

Публичные карточки всех восьми моделей получены без авторизации и без генераций. Снимок: `docs/chat-roleplay-provider-snapshot-2026-10-10.json`. У Skyfall и Aion-RP окно 32768; остальные имеют большее окно. У всех достаточно вместимости для потолка приложения 20000, входа Вселенной до 16000 и выхода до 4000. Младшие тарифы и гостевой предел 6000 сохранены.

Все семь новых моделей: max_tokens=1000, temperature=0.7. Моделям без reasoning не отправляются параметры reasoning. Aion 2.0 запрашивает `reasoning: {effort: "none", enabled: false, exclude: true}`; прямой API Aion поддерживает none, но KodikRouter перечисляет reasoning без отдельного reasoning_effort. Поэтому фактическое отключение через шлюз не подтверждено, в UI постоянно видимо предупреждение о коротком или незавершённом ответе. Источник: https://www.aionlabs.ai/docs/api-reference/.

Aion 3.5 Mini сохраняет прежние max_tokens=4000 и reasoning low/exclude. У неё обязательные рассуждения, которые делят выходной лимит с видимым текстом. Изменений относительно режима, понравившегося владельцу, нет. Таймаут ожидания HTTP/открытия потока для всех восьми тестовых моделей — прежние 60 секунд. Это не предел полной длительности потока и не замер скорости.

## Стоимость и валюта

Карточки KodikRouter дают долларовые ставки за миллион токенов: Cydonia 0.30/0.50; Venice 0.20/0.90; UnslopNemo 0.40/0.40; Skyfall 0.55/0.80; Aion-RP и Aion 2.0 0.80/1.60; Hermes 1.00/1.00; Aion 3.5 0.70/1.40.

Поля Model.pricePer1MInput/Output в проекте рублёвые. Для нового каталога сохранён расчётный курс 96.7 RUB/USD из исходного чата и прежней котировки Aion 3.5. Это фиксированная каталоговая оценка с округлением до копеек, не текущий курс ЦБ, не подтверждённое списание, не новый курс для usage.cost. Произвольно добавлять наценку шлюза к этим оценкам не стали. Фактический механизм учёта не изменён: usage.cost обрабатывается прежним кодом с курсом для учёта, а окончательные рублёвые списания сверяются с журналом провайдера. Прежние котировки снятых моделей остаются доступны для учёта запросов, начатых до переключения.

## Выпуск

Подготовлен только новый SQL `prisma/migrations/20261010220000_roleplay_testing_catalog/migration.sql`. Он добавляет семь строк, сохраняет id существующей Aion 3.5, обновляет восемь тестовых строк и деактивирует четыре снятые модели. После применения к нынешним 14 строкам ожидаются 21 строка в БД и 17 активных (9 основных + 8 тестовых).

Сначала выложить код, затем после свежего бэкапа выполнить этот новый файл одной транзакцией через Adminer. Старые два SQL повторять не нужно: первый из них активирует прежние модели. Seed на production запускать нельзя. Не изменять фиктивно историю Prisma.

После SQL проверить восемь isTesting, девять обычных моделей, четыре неактивных строки, сохранность прежних id и ссылок. Платные проверки качества русского, удержания роли, времени ответа, стоимости и отключения reasoning Aion 2.0 остаются отдельной задачей. Название Uncensored не является гарантией поведения конкретного маршрута.
