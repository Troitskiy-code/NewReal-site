# Общий публичный каталог в Telegram

Telegram Mini App использует все публичные карточки сайта, без отдельного ручного отбора.
Публикация и снятие с публикации действуют в обоих интерфейсах. Свои приватные персонажи
остаются доступны автору, чужие приватные карточки закрыты, в том числе по прямым ссылкам,
в метаданных чата и изображениях.

Единое правило применяется к каталогу, поиску, рекомендациям, стартовым подборкам,
чатам, избранному, гостевому чату и аватарам. Старые записи TelegramCatalogEntry
не используются для предоставления доступа. Страница /admin/telegram-catalog
объясняет новый порядок; прежний API ручного изменения отбора возвращает 410.

Миграции и новые переменные не нужны. Ограничения покупок внутри Telegram сохраняются.
Проверки используют отдельную тестовую базу и заглушки AI.

Для оформления Telegram используется готовый новый логотип сайта:
public/icon-maskable-512x512.png — непрозрачный тёмный фон, белая лента и малиновый акцент.

Иконки @newverse_test_bot и @newverse_updates обновлены через Telegram Web и проверены
в карточках профилей. Перед выпуском каталог сайта содержал 152 публичных карточки,
а Telegram — 12 карточек прежней подборки.

Проверки: verify:telegram — 123 сценария; TypeScript и lint изменённых модулей — без ошибок.
Браузерные ожидания приведены к нынешнему интерфейсу: палитра #0c0b12, баланс с иконкой
без суффикса VC на узком экране, подсказка списания VC по кнопке информации.
