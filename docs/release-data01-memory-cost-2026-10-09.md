## Состав

- DATA-01: серверный снимок заказа и рекламного источника, opaque order_id в целях, отдельные advisory receipts, read-only финансовый отчёт. Некорректные goal/orderId отклоняются до SQL, включая старую подписку без плана. Реестры расходов и рекламные callbacks не используются для начисления VC.
- Память этапа 0: фильтр известных команд, сохранение ручных core-фактов, условная транзакционная запись core/зеркала, канонический ответ refresh после конфликта, сводка из выбранных исходных цитат, actor/план у regenerate/refresh. Память v2 не реализована.
- COST-01: нормализация Float-оценок отдельно от строгих сумм выписки; единый SSE-парсер в ответе и учёте; failed/cancelled расход сохраняется без успешного ответа/списания VC. Штатное length-завершение и «Продолжить» сохранены.
- Тест целей вовлечения загружает новый реальный модуль SSE вместо устаревшего списка зависимостей. Assertions не удалены и не ослаблены.

Тарифы, VC, квоты аватаров, реклама и настройки окружения не менялись. Для памяти и COST-01 новые env/cron/миграции не нужны. Опциональный PAYMENT_TEST_USER_IDS нужен только для явного исключения покупок владельца; без него обычные покупки не объявляются тестами по догадке.
